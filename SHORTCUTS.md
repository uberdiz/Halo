# SAINT Keyboard Shortcuts

## Global Shortcuts

- **Ctrl+K** - Open command palette
- **Ctrl+,** - Open Settings
- **Esc** - Close current dialog or palette
- **Ctrl+1 to Ctrl+9** - Navigate to sidebar pages (1-9)
- **Meta+S** - Open overlay (Linux/Windows) - *New*

## Overlay Shortcuts

- **Esc** - Close overlay
- **Tab** - Switch between input and output in overlay
- **Enter** - Submit query in overlay
